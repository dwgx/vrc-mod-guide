上手流程

改模 = 拿一个基础模型(素体/OriginalBase),换衣服、调材质物理骨骼、加表情开关,上传成自己的 Avatar。最小闭环:

  1. 装 VCC(Creator Companion),它自动装对的 Unity 版本和 SDK
  2. VCC 新建 Avatar 项目,装 ModularAvatar + lilToon(衣装常依赖)
  3. 导入素体 .unitypackage,拖进场景,确认有 VRC Avatar Descriptor
  4. 导入衣装,用 ModularAvatar 拖到素体上(Setup Outfit)自动适配骨骼
  5. 调材质(lilToon/Poiyomi)、PhysBone 物理骨骼、表情开关
  6. VRChat SDK 面板登录 → Build & Test 本地试穿 → 没问题再 Build & Publish 上传
账号要求上传 Avatar 需要账号达到 New User 信任等级(约游玩数小时后自动获得)。

Unity 版本(必读)

一句话:别手动选 Unity 版本,更别现在上 Unity 6 永远让 VCC 决定并安装版本。手动升级会导致上传后内容加载不出来。

截至本页编写时,VRChat 官方要求 Unity 2022.3.22f1(SDK 3.6.0+ 起官方支持 2022.3 线)。这个号会变,唯一可信来源是官方页和 VCC 实际安装的版本。

  • 官方版本页:creators.vrchat.com/sdk/upgrade/current-unity-version
  • 要换 Unity 6 吗? 目前 VRChat 没公布任何 Unity 6 迁移计划,官方反而明确警告不要自行升级。以后真要换,也是等 VCC 推送、跟着 VCC 迁移,绝不手动改 Unity Hub。

优化 / Quest 适配

主题要点
性能评级5 级(Excellent~Very Poor)。PC/移动端各有三角面、材质、PhysBone、纹理内存上限。官方表(已核实)
Quest 适配用 VRCQuestTools 一键转换;PC/Quest 上传同一 blueprint,骨架必须一致。跨平台(已核实)
减面/减材质合并为 1 个 SkinnedMesh、减材质槽、纹理图集、控 VRAM。官方优化建议(已核实)
物理骨骼弃用 Dynamic Bones 改 PhysBones;Android 上限 8 组件/64 transform/16 碰撞器。
Fallback自定义 fallback 需全平台构建 + Good 及以上。官方(已核实)

常见报错排查

现象排查
变成 error avatar纹理过大/材质过多/缺 shader;先看 SDK 面板的 build 报告
missing script导入的 unitypackage 缺依赖,确认装了对应 SDK/MA/着色器版本
blueprint ID 被清空试图加载非自己拥有的 avatar;新建或重置 Pipeline Manager 的 blueprint
shader 全粉/全白缺着色器,导入 lilToon/Poiyomi 后重新指定材质
衣装穿上错位骨架命名不匹配;用 MA Setup Outfit 或检查 Armature 层级
